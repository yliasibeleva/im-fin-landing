# Настройка Telegram-уведомлений

## Шаг 1 — Создать бота

1. Откройте Telegram, найдите **@BotFather**
2. Напишите `/newbot`
3. Придумайте название: например `Империя Финанс CRM`
4. Придумайте username: например `imperiya_crm_bot`
5. BotFather пришлёт токен вида:
   ```
   1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   — это ваш **TELEGRAM_BOT_TOKEN**

---

## Шаг 2 — Получить Chat ID

1. Напишите вашему новому боту любое сообщение (например `привет`)
2. Откройте в браузере (вставьте свой токен):
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
3. Найдите в ответе строку:
   ```json
   "chat": {"id": 123456789, ...}
   ```
   Число `123456789` — это ваш **TELEGRAM_CHAT_ID**

---

## Шаг 3 — Вставить в .env

Откройте файл `D:\РС\Визитка\buh-bot\.env` и заполните:

```
TELEGRAM_BOT_TOKEN=1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TELEGRAM_CHAT_ID=123456789
```

---

## Шаг 4 — Перезапустить CRM

Закройте и откройте **СРМ Бухгалтерия** с рабочего стола (или запустите `запустить_дашборд.bat`).

---

## Когда приходят уведомления

| Событие | Сообщение |
|---|---|
| Добавлена новая компания | 🏢 **Добавлена новая компания** |
| Дедлайн отмечен выполненным | ✅ **Дедлайн выполнен** |
| Отчёт отмечен сданным | 📄 **Отчёт сдан** |
| Добавлена новая задача | 📋 **Новая задача** |
| Задача выполнена | ✅ **Задача выполнена** |
| Зафиксирована ошибка бухгалтера | ⚠️ **Зафиксирована ошибка** |

---

## Проверка работы

После настройки нажмите кнопку **«Проверить»** по адресу:
```
http://localhost:8000/tg/test
```
Должно прийти тестовое сообщение в Telegram.
